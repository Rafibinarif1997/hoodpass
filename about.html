ABOUT THE PROJECT

JUST A MEME PLAYGROUND.

Trump Chaos is a fictional, unofficial parody website built around silly interactive games and meme-making. The goal is entertainment, not political campaigning.

WHAT'S INSIDE?

  • Four browser-based mini-games.
  • A local meme generator with PNG download.
  • Responsive design for phones and desktops.
  • No login, wallet, database, or external API required.
  • All game state runs locally in the browser.
TRUMP CHAOS is not affiliated with Donald Trump, his campaign, or any political organization. It does not represent an endorsement or opposition.
