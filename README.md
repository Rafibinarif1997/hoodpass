# Trump Chaos

Standalone static parody website.

## Files
- index.html — homepage
- games.html — four playable games
- meme.html — meme generator + PNG download
- about.html — project info
- style.css — shared styling
- app.js — shared navigation helpers
- assets/trump.png — character asset

## Run
Open `index.html` directly in a browser, or upload the whole folder to GitHub Pages / Netlify / Cloudflare Pages.

No npm, build step, backend, wallet, or database is required.

## Important
This is an unofficial parody/entertainment site and is not affiliated with Donald Trump or any political campaign.
