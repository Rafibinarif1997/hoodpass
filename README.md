# Pixel Forge

Zero-upload, browser-only procedural NFT collection generator. Open `index.html` in a browser. Choose bear, cat, monkey or robot; select theme and quantity; generate; download PNGs and JSON metadata as ZIP. No API keys or server needed. The artwork is programmatically drawn (not AI-generated). Export metadata contains local image paths that must be replaced with public URIs before minting.

## GitHub Pages
Upload `index.html` to the root of a public repository. In Settings → Pages, choose Deploy from a branch, main, / (root). Visit the Pages URL when deployed.
